## 1. SCP란?

> `scp`(secure copy)는 SSH 프로토콜을 기반으로 원격 서버 간 안전하게 파일이나 디렉터리를 복사(업로드/다운로드)하는 명령어
> SSH와 동일한 포트, 인증 방식(비밀번호/키 등)을 사용

---

## 2. 기본 구조

```bash
scp [옵션] <소스> <목적지>
```

- **<소스>**, **<목적지>** :  
  - 로컬 경로(예: `/home/user/file.txt`)
  - 원격 경로(예: `user@host:/경로/파일`)

---

## 3. 사용 예제

### 1) 로컬 → 원격 서버로 파일 전송

```bash
scp /path/to/localfile.txt username@remote_host:/home/username/
```

### 2) 원격 서버 → 로컬로 파일 다운로드

```bash
scp username@remote_host:/home/username/remotefile.txt /path/to/local/
```

### 3) 디렉토리 전체 전송 (재귀 옵션 -r)

```bash
scp -r ./local_folder username@remote_host:/home/username/
scp -r username@remote_host:/home/username/remote_folder ./local_destination/
```

### 4) 포트번호 지정(기본 22번이 아닐 때)

```bash
scp -P 2222 file.txt user@host:/path/
```

### 5) 여러 파일 한 번에 전송

```bash
scp file1.txt file2.txt user@host:/path/
```

## 4. tar 명령어와 조합 예시

용량이 큰 폴더를 전송하거나, 파일 권한‧소유주 정보까지 보존하며 전송하려면 `tar`와 `scp`를 함께 사용하면 효율적

### 1) 디렉토리를 tar로 압축하여 전송

#### 로컬→원격: tar로 압축 후 scp 전송

```bash
tar czf local_folder.tar.gz ./local_folder
scp local_folder.tar.gz user@host:/path/
# (원격) 압축 해제
# ssh user@host "tar xzf /path/local_folder.tar.gz -C /path/"
```

#### 원격→로컬: 원격에서 tar로 압축하고 가져오기

```bash
ssh user@host "tar czf - -C /home/username remote_folder" > remote_folder.tar.gz
# or 원격 전체를 로컬에서 풀기
ssh user@host "tar czf - -C /home/username remote_folder" | tar xzf - -C ./local_destination/
```

### 2) pipe를 이용해 바로 압축 전송(디스크 공간 절약)

```bash
tar czf - ./local_folder | ssh user@host "tar xzf - -C /path/"
# ↳ 로컬에서 압축 → ssh로 원격에서 바로 풀기(중간 파일 안 남음)
```

## 5. scp 주요 옵션 정리

| 옵션 | 설명 |
|------|------|
| `-r` | 폴더/하위 디렉터리까지 모두 재귀적으로 복사 |
| `-P` | 포트 번호 지정 (`-p`와 다름) |
| `-p` | 원본 파일의 권한/타임스탬프 보존 |
| `-C` | 전송 중 압축(Compress) 사용, 큰 파일 전송 시 유용 |
| `-i` | 특정 SSH 개인키 파일 사용 |

---

## 6. 실전 팁 & 유의사항

- **폴더 전송은 압축 후 전송이 빠를 수 있음(tar+scp 활용)**
- **SSH 비밀번호 대신 공개키 인증을 사용하면 자동화/보안성이 높아짐**
- **방화벽, 네트워크 제한이 있는 경우 SSH 포트, 보안그룹, IP 허용 등을 반드시 확인**
- **`-v`(verbose) 옵션으로 상세 로그 확인 가능**
